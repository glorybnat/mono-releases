# Mono downloads

Installers for **Mono**, the task app with lists, sub-lists and sharing.
Use it on the web at <https://mono.majdb.com>.

Download the latest version from **[Releases](https://github.com/glorybnat/mono-releases/releases/latest)**:

| System | File |
|---|---|
| Mac (Apple Silicon) | `.dmg` |
| Windows | `-setup.exe` (or `.msi`) |
| Linux | `.AppImage` (or `.deb`) |

Installed apps update themselves.

**First launch.** The installers aren't signed with a paid certificate yet:
- Mac: System Settings → Privacy & Security → **Open Anyway**. If macOS says the app is damaged, run `xattr -cr /Applications/Mono.app` once.
- Windows: **More info → Run anyway**.

This repository holds downloads only.
